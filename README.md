# Online Shoppers Purchase Prediction

## 1. Problem Statement

The objective of this project is to develop a machine learning classification system that predicts whether an online browsing session results in a purchase. Five classification algorithms will be implemented and evaluated, followed by an interactive Streamlit application that allows users to select a trained model, upload test data, and examine its performance.

This project is being developed as part of the BITS Pilani Work Integrated Learning Programmes (WILP), M.Tech in Artificial Intelligence and Machine Learning, Machine Learning — Assignment 2.

## 2. Dataset Description

**Dataset:** Online Shoppers Purchasing Intention  
**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)

The dataset contains 12,330 online browsing sessions and 17 input features describing browsing behaviour, page interactions, visitor characteristics, traffic sources, and visit timing.

The target variable is `Revenue`:
- `True`: The session resulted in a purchase.
- `False`: The session did not result in a purchase.

The dataset satisfies the assignment's minimum requirements of 12 features and 500 instances. Further exploratory analysis and data-quality checks will be documented as the project progresses.
